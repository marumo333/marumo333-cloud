# semantic-similarity-rating skill（arXiv:2510.08338）

購入意向・同意・満足など、5点 Likert を LLM 合成回答者から取るときに使う。席は増やさない。親が手順を実行する。検証用 subagent は出さない。モデルは grok-4.7-xhigh。

出典: Maier et al., *LLMs Reproduce Human Purchase Intent via Semantic Similarity Elicitation of Likert Ratings*, https://arxiv.org/abs/2510.08338 。参考実装: https://github.com/pymc-labs/semantic-similarity-rating 。

## いつ使う / 使わない

使う:

- 合成パネルで Likert の分布か平均を人間調査と比較する
- 概念テストの購入意向を、数値の一点推定ではなく分布で残す
- 評点の理由文も同時に欲しい

使わない:

- 価格の上下当てや売買判断
- 訓練データに無い領域の嗜好を「真実」として扱うこと
- 人口統計を省略したまま概念の順位を信じること（論文では人口統計なしで順位相関が落ちる）

## 禁止（直接 Likert）

LLM に `1`〜`5` の整数だけを答えさせない。中心回帰し、分布が人間と合わない（論文の Direct Likert）。自由文のあと別 LLM に整数へ要約させる Follow-up Likert も分布は改善するが、下の埋め込み写像より劣りやすい。

## 手順

1. **人格**: 年齢・性別・所得帯・地域など、比較対象の人間回答者と揃う属性を system に書く。属性を空にすると分布は人間に近づいても概念順位の信号が落ちる。
2. **刺激**: 概念の説明文、可能なら概念画像を渡す。
3. **自由文**: 「この商品を買う可能性はどれくらいですか？」に短く答えさせる。system に「質問には簡潔に答える」を足す。温度は論文の主結果に合わせ `0.5` を既定とする。同じプロンプトから少数回サンプルして平均してよい（論文は n=2）。
4. **参照文**: 各 Likert 点（1〜5）に短いアンカー文を1つずつ置く。最低は購入が起きにくい、中間は迷い、最高は購入の意向。中間2点はその間の意味にする。製品固有の言い回しは避け、領域に依存しない短文にする。言い回しの違う集合を複数（論文は6）用意し、回答ごとに各集合の分布を平均する。
5. **埋め込み**: 自由文と各アンカーを同じ埋め込みモデルでベクトル化する。論文は OpenAI `text-embedding-3-small`。手元では同等の文埋め込みでもよいが、集合内でモデルを混ぜない。
6. **類似度**: コサイン類似 `γ(σ_r, t) = (v_σ · v_t) / (|v_σ||v_t|)`。実装では `(1 + cosine) / 2` に写してから使ってもよい（参考リポ）。
7. **分布**: 集合 Σ ごとに

   `p(r) ∝ γ(σ_r, t) − min_ℓ γ(σ_ℓ, t) + ε·1[r = argmin]`

   を正規化する。既定は `ε = 0`、温度 `T = 1`（`p_T(r) ∝ p(r)^{1/T}`）。`ε = 0` だと最小類似の点は確率0になる。平滑が要るときだけ `ε > 0` を足す。
8. **集計**: 回答者（とサンプル）の pmf を平均し、調査の応答分布と平均購入意向 `PI = Σ r·p(r)` を出す。自由文はそのまま定性の材料にする。

## 人間データがあるときの合格線

論文の尺度に揃えるときだけ使う。無いときは分布と平均の報告で止める。

| 指標 | 意味 | 論文の目安 |
| --- | --- | --- |
| KS 類似 | `1 − KS距離`（順序を尊重） | 平均 0.85 超を目標帯 |
| 相関到達度 ρ | `E[R_xy] / E[R_xx]`。`R_xx` は人間の半分割テスト再テスト | 約 90% |

直接 Likert で順位相関だけ高く見えることがある。分布が崩れていれば不合格とする。

## 参照文の置き方

- 手で短く書き、複数集合で言い回しをずらす
- 調査ごとに人手で寄せすぎると、その調査専用になり他調査へ持ち出せない
- 同意尺度など購入以外へ広げるときは、同じ強度勾配でアンカーを作り直す

例（購入意向・1集合。本番は言い回し違いを複数用意する）:

1. It's rather unlikely I'd buy it.
2. I probably wouldn't buy it.
3. I'm not sure whether I'd buy it.
4. I'd probably buy it.
5. It's very likely I'd buy it.

## 出力に残すもの

各合成回答について次を残す。秘密と個人情報は書かない。

- 使った属性（個人が特定できない粒度）
- 自由文
- 参照集合 ID
- 5点の pmf と期待値
- 埋め込みモデル名と `ε` / `T`
